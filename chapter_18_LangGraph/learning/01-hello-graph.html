Your first graph

A graph is a set of nodes joined by edges. Every node reads the shared state and returns only what it changed.

Key points

  • 1State is a plain dict shared by every node
  • 2A node returns only what it changed
  • 3Build it, compile() it, invoke() it

Try it

$ python 001_Hello_Graph.py
